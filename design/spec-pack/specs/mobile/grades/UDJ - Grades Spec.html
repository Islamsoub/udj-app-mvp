UDJ — Grades Spec

Implementation reference for the polished Notes / الدرجات screen (relevé) and its two sheets — GradeCalculatorSheet and GPAHistorySheet — in the Soft Elevated language. The GPA becomes a jade hero card (Présence parity); subjects become Soft Elevated cards. Values are the source of truth — wire them as tokens, don't hardcode. Supports light, dark and RTL. Targeted at the 15+ off-grid literals, 10+ hardcoded hex, and the divider/banner token bugs from the investigation — not a rewrite.

0 Key decisions

Decision 1 · GPA header

Jade full-bleed header → jade gradient HERO CARD inside the scroll.

Adopt the Présence hero treatment: the same 150° jade→jade700 gradient card (rHero 22, brand glow) now holds the GPA, mention badge and credits, sitting on the app bg with normal side padding. This kills the status-bar bleed and the four fragile fixed header heights (305/235/195/138) — the card sizes to its content — and makes Notes visually rhyme with Présence (the app's other "headline metric" surface).

Hero card. One intrinsic height across all states.
Decision 2 · Subject cards

Soft Elevated (surface + cardShadow), drop the borders.

Same as every other card in the app: surface · rTile 18 · cardShadow, no 1px border, no off-token radius 14. The 4 metrics move into a recessed surface2 strip so the card reads as one object.

surface + cardShadow + rTile 18.
Decision 3 · The 4-column grid

Keep the four metrics, drop the divider grid.

CC · CF · COEF · NF stay (students expect them), but the heavy vertical/horizontal rules — which currently mis-use textSecondary as a divider colour — are removed. Four equal flex cells in one surface2 strip, separated by space (optional 1px hair hairlines at 60% height). NF is the result, so it carries the level colour. A real full-width progress bar (NF/20) replaces the 3px / hardcoded-298 bar.

4 cells, no rule-grid, NF emphasised, % progress bar.
Decision 4 · Mention badge in dark mode

On the gradient: white@18% pill + level dot. Off-gradient: tokenised mention map.

Because the hero gradient is identical in dark mode (brand anchor, per Présence), the badge is #fff@18% bg + white text + a small level dot — so there are no per-mention dark colours to maintain. The hardcoded light-only colorMap is replaced by mentionColor(score) → theme tokens (§7) for any place a mention shows on a light surface.

white@18% on hero · mentionColor() token map elsewhere.

7 Dark mode, RTL & mention map

Dark mode

  • Hero gradient unchanged — jade is the brand anchor; mention badge stays #fff@18%/white, so no per-mention dark colours are needed.
  • Header = bg (#0E1512); scroll shadow → 1px hair border. Status-bar barStyle token-driven (header is no longer jade).
  • Cards = surface (#17211D) + dark cardShadow; metric strip = surface2; progress track = sunken; hairlines = hair.
  • Status pills + NF + bar use lifted tokens: jade #2BB989, amber #F0A84B, danger #FF6B6B.
  • Segmented track = sunken; active = jade. Chart grid = hair, line = jade lifted, band = jadeFaint.

RTL (Arabic)

  • Root direction: rtl — title right-aligns; calc button to the left; segmented mirrors (S1 right, S2 left).
  • Hero label/credits right-align; GPA stays LTR ("12.28", DM Mono); credits use Arabic-Indic ("٢٤/٣٢"); history affordance flips corner.
  • Metric cells reorder right→left (CC on the right); values stay LTR DM Mono; labels mirror.
  • Status pill + at-risk hint mirror to the leading edge; progress fill uses inset-inline-start.
  • Mention text Arabic (§9); both sheets mirror; chart axis mirrors (S1 on right), numerals LTR. Font → Noto Naskh Arabic.
