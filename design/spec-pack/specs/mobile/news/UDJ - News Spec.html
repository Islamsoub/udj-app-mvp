UDJ — News Spec

Implementation reference for the polished Actualités / الأخبار screen, its FilterRow, HeroCard, ArticleCard and the NewsArticleScreen detail, in the Soft Elevated language. Category colours flow through the existing getNewsCategoryColors() token map (shared with Home) — no new hex. Values are the source of truth; wire them as tokens. Supports light, dark and RTL. Targeted at the 18+ off-grid values, the 14 hardcoded category hex, and the un-i18n'd labels from the investigation — not a rewrite.

0 Key decisions

Decision 1 · HeroCard

Image card with a scrim — not a brand gradient.

The jade gradient is reserved for metric heroes (GPA, Présence). News is image-led, so the feature card stays an image card: cover image (or surface2 placeholder), a category/urgent pill over the top, and a bottom scrim (transparent→black) carrying the title + meta when an image exists. With no image it degrades to the current "image area + surface footer" so text stays legible. rTile 18 + cardShadow.

Image card · scrim overlay · danger "Urgent" pill (not a hardcoded string).
Decision 2 · ArticleCards

Soft Elevated (surface + cardShadow), drop the borders.

Same as every other list card: surface · rTile 18 · cardShadow, no 1px border, no off-token radius 14. Thumbnail grows from the tiny 37×35 to a proper 56×56 rounded tile.

surface + cardShadow + rTile 18 · 56×56 thumb.
Decision 3 · Filter chips

Keep the scrolling row, fix it to tokens.

The horizontal chip row is the right pattern — just tokenise it: height 36, radius full (9999), active = jade / #fff, inactive = surface2 / text2 (no border). Container height to the grid. Labels stay i18n'd (already correct).

36 tall · full radius · jade active · surface + hair2 inactive.
Decision 4 · 7 categories → token pairs

Reuse getNewsCategoryColors(); map the long tail to slate.

Five distinct hues + slate fallback (danger is reserved for the Urgent state, never a category): Officiel→jade · Événements→blue · Scolarité→amber · Sport→violet · Jeunesse→slate · Sponsors→slate · Général→slate. The same map already powers Home's NewsCard, so a category reads identically everywhere and is dark-mode-correct for free.

Shared token map · Sport=violet (was a danger-like pink — collided with Urgent).

  • fix Category colours de-hardcoded. The 14 hex values in getCategoryColor() → the shared getNewsCategoryColors() token map (§8). Dark-mode-correct, identical to Home.
  • fix Category pill labels i18n'd — no more raw API string + capitalizeFirst. Map cat → t('news.cat.*').
  • fix "Officiel · Urgent" localised (was a hardcoded string); the Urgent state uses the danger token, separate from any category.
  • chg ArticleCards Soft Elevated (surface + cardShadow + rTile 18). fix radius 14 → 18, margin 15 → padInline 16, height 122 fixed → intrinsic.
  • fix Thumbnail 37×35 → 56×56 rounded (radius 12).
  • chg HeroCard stays an image card but tokenised: rTile 18, height intrinsic (was 229 fixed), scrim for text over images, danger Urgent pill (dot 8, was 11).
  • chg FilterRow tokenised: container 52 (was 72), chip 36 / radius 9999 (was 41 / 22), inactive surface + 1px hair2, active jade.
  • chg Title 18 → 24/26 (root-tab scale).
  • fix 18+ off-grid values → 4px grid; 4 non-standard radii → tokens.
  • keep All 6 states, offline-first SQLite cache, bilingual titleFr/titleAr, i18n filter labels, bookmark persistence, relative timestamps.

7 Dark mode & RTL

Dark mode

  • Header = bg; scroll shadow → 1px hair border. Cards = surface (#17211D) + dark cardShadow.
  • Category pills now theme-correct via the token map — jadeFaint/blueBg/amberBg/examBg/slateBg lift in dark automatically (the bug this fixes).
  • FilterChip inactive = surface + 1px hair2 (surface2 is ≈bg in light, so it would vanish); active = jade (#2BB989). Thumbnail placeholder = surface2.
  • Hero scrim unchanged (always darkens toward black for text); Urgent pill = dangerBg/danger lifted.
  • Detail body text = text1; source pill over image stays #fff@16%/#fff in both themes.

RTL (Arabic)

  • Root direction: rtl — title right-aligns; FilterRow scrolls right→left, first chip ("الكل") on the right.
  • ArticleCard mirrors: thumbnail on the right, category pill leads right, time + unread dot to the left.
  • Hero Urgent pill uses inset-inline-start → flips to the top-right.
  • Detail back button flips to the right; date numerals use Arabic-Indic mono; action bar mirrors (Partager leads).
  • Titles use titleAr; relative time localised ("منذ ١١ يوماً"); font → Noto Naskh Arabic.
