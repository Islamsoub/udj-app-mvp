UDJ — Schedule Spec

Implementation reference for the polished Emploi du temps / جدول الحصص screen (Agenda tab) and its CourseDetailSheet, in the Soft Elevated language. The class card is the same ScheduleCard as Home (5px course rail + pills) wrapped in a timeline. Values are the source of truth — wire them as tokens, don't hardcode. Supports light, dark and RTL. Targeted at fixing the 25+ off-grid values, raw font strings and flat cards found in the investigation — not a rewrite.

Key decision · timeline vs. stacked

Keep the timeline — but make the card the shared ScheduleCard.

The dedicated Agenda screen earns its structure: the gutter + connector give a chronological spine that surfaces gaps ("Pause de 2 heures") and reads as a real day-planner — something Home's flat glance list can't. Dropping to a plain stack would make Agenda a redundant, taller copy of Home. The timeline's only real sins were off-grid values and a bespoke flat card, not the concept.

So: retain gutter + connector dot/line, but rationalise them onto the 4px grid, and replace the bespoke flat card with the canonical ScheduleCard (Home parity: surface · rTile 18 · cardShadow · 5px rail · tokenised pills) in a timeline variant. One component, two variants — the gutter owns the time, so the card hides its top time-line and shows the full range as a pill.

Recommendation: timeline layout, grid-aligned, shared ScheduleCard. ~30 numeric fixes, 0 concept changes.

One component, two variants. Home uses variant="glance" (mono time line at top, room + status pills, title 16.5). Agenda uses variant="timeline" (no top time — the gutter owns it; full range pill + status pill, room folded into the prof line). The timeline title drops to 15.5 in Latin only (FR) — these strings are longer than Home's and read heavy at 16.5; Arabic keeps 16.5. Everything else (surface/radius/shadow/rail tokens) is identical across both. Status pill must hug its content (never a fixed width/height) — that's what clipped "À venir" to "À".

7 Dark mode & RTL

Dark mode

  • Header bg = bg (#0E1512); scroll shadow becomes a 1px hair bottom border (shadows read poorly on near-black).
  • DayCell selected = jade (#2BB989) + white text; weekend cells = sunken (#0A0F0D) + text3 — recessed, never surface2 (which is lighter than bg in dark).
  • Cards = surface (#17211D) + dark cardShadow; range pill = surface2.
  • Course rails + connector dots use the dark palette column (§6, ~12% lighter) so they stay visible on dark cards.
  • Status pills follow lifted tokens (blueBg/blue, jadeFaint/jadeText, slateBg/slate dark).
  • Connector line = hair (#fff @8%); gap dot ring = hair2.
  • StatusBar barStyle is token-driven (light-content in dark) — the bug this fixes.

RTL (Arabic)

  • Root direction: rtl — title right-aligns; week nav prev/next swap (chevrons flip); DayStrip lays out right→left.
  • Gutter + connector move to the right edge; the rail uses inset-inline-start → flips automatically.
  • Times stay LTR ("08:00 – 09:30", DM Mono) but DayStrip dates & note timestamps use Arabic-Indic numerals ("الخميس ١١ يونيو").
  • Day subtitle "اليوم – الخميس ١١ يونيو"; break label "استراحة لساعتين".
  • Detail-sheet rows mirror — label leads (right), value to the left; StatusPill mirrors.
  • Font switches to Noto Naskh Arabic; mono times/codes stay Latin DM Mono. Verify dark + AR together.

8 Course-colour palette (recap)

Same 12-colour sequential palette as Home/Notifications — assigned by stable index courseColor(courseId % 12) so a course keeps one colour across Home rail, Agenda rail, connector dot and the detail-sheet dot. Brand jade is excluded from the rotation so a course rail never reads as "live/active" (that's reserved for the En-cours state). Reference assignment for the screens in the screenshots is below.
