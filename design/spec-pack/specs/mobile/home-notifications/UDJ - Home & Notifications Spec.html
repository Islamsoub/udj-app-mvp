UDJ — Home & Notifications Spec

Polish reference for the two remaining shell surfaces. Home / Accueil moves to the Soft Elevated + Icon-led language (matches Profile / Présence); Notifications uses the compact stack header + Soft Elevated grouped cards. Values are the source of truth — wire them as tokens, don't hardcode. Both support light, dark and RTL. New tokens (12-colour course palette + category map) are in §C.

7 Dark mode & RTL

Dark mode

  • Header bg = bg (#0E1512); stat cards = sunken (#0A0F0D) + hair border — darker than bg so they stay recessed (never surface2, which is lighter than bg in dark); stat value = jade (#2BB989).
  • Scroll shadow becomes a 1px hair bottom border (shadows read poorly on near-black).
  • Schedule/news cards = surface (#17211D) + dark cardShadow; room pill = surface2.
  • Course rails use the dark palette column (§C) — ~12% lighter so rails stay visible on dark cards.
  • Category pills + "En cours" follow lifted tokens (jadeFaint dark, blueBg, amberBg).
  • Status-bar glyphs + bell are token-driven — never hardcode dark content.

RTL (Arabic)

  • Root direction: rtl — date moves to the right, bell to the left; greeting + sections right-align.
  • Greeting "مرحباً، أحمد" — firstName still jade inline; letter-spacing → 0.
  • Stat row + section "Voir tout / عرض الكل" mirror; stat values use Arabic-Indic numerals ("١٢٫٣").
  • Course rail uses inset-inline-start → flips to the right edge automatically.
  • Schedule time stays LTR ("08:00 - 09:30", DM Mono); room/status pills mirror.
  • Font switches to Noto Naskh Arabic; verify dark + AR together.

C

Colour tokens & new systems

Shared by both screens. Existing token swatches + the new 12-colour course palette + the notification category map.

1 Existing tokens used

Light

Dark

All chrome (surfaces, text, hair, pills, skeleton) swaps through these existing tokens — Home & Notifications add no new theme primitives, only the two systems below. On-gradient whites are not tokenised (none needed here — neither screen has a jade hero).

2 Course-colour palette new · 12 sequential

Assign by stable index: courseColor(courseId % 12) — same course = same colour everywhere (Home rail, Agenda, course detail). Rails are 5px slivers on a surface card, so saturation is safe. Dark column is ~12% lighter for visibility on dark cards. Brand jade is intentionally excluded from the rotation so course rails never read as "live/active".
