UDJ — Account Info Spec

Implementation reference for the polished Informations du compte / معلومات الحساب screen, in the Soft Elevated language. Reached from Settings → Informations du compte (also from any Profile detail-row tap). A read-only identity screen — no editing, no overlays. Values are the source of truth; wire as tokens, don't hardcode. Supports light, dark, RTL.

Offline cachedShared OfflineBanner above the identity block (offlineBg, 1px warningBorder, 8×8 offline dot, 12 offlineText). Status pill flips dot→offline color and label→"Hors ligne" (text2). Cached identity renders normally.

8 Dark mode & RTL

Dark mode

  • All surfaces/text/hair swap via tokens; chips lift accents (jade→#2BB989 etc.).
  • Avatar ring inner halo uses surface so the disc still separates from the dark bg.
  • Status pill: jadeText→#5FD3A6 on jadeFaint@16%.
  • Status bar glyphs token-driven — never hardcode dark-content.

RTL (Arabic)

  • Root direction: rtl — back button + chevron-free rows mirror; chips move to the trailing edge, values to the leading edge.
  • Identity block stays centered (direction-agnostic).
  • Copy from t('account.*'); ID, email, phone stay Latin/DM Mono in both languages.
  • Font switches to Noto Naskh Arabic; verify dark+AR together.
