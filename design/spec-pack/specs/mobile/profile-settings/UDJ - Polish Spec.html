UDJ — Polish Spec

Implementation reference for the chosen directions: Settings → Inset Grouped and Profile → Soft Elevated. Values are the source of truth for the prototype; wire them as tokens (don't hardcode in components). Supports light, dark, and RTL.

1 · The two directions

Settings

Inset Grouped

  • Rounded white cards (radius 16) floating on the tinted background with 16px side margins — replaces full-bleed hairline rows.
  • Soft inner hairline rgba(28,35,32,.07); never on the last row.
  • Large title header (25/800) with a back button; section labels sentence-case (13/600).
  • Row min-height 52; label 15.5/500; value 15/400 secondary.
Profile

Soft Elevated + Icon-led

  • Hero student card: jade gradient, avatar, inline QR + live "regenerates in 47s" affordance; tap → fullscreen QR.
  • Quick-action tiles (Documents / Présence / Alertes).
  • Detail rows carry tinted icon chips (34×34, radius 11); shadow-elevated cards, no borders.
  • Floating jade nav bar with filled active tab.

2 · Color tokens

Light

Dark

Accent chips (jade/amber/violet/blue/slate) pair a tint stroke with a tintBg fill at ~12% (light) / ~16% (dark). On dark, jade lifts to #2BB989 for legibility; text accents use jadeText #5FD3A6.

3 · Type scale

RoleFamilySizeWeightTracking

Fonts: Plus Jakarta Sans (UI), DM Mono (IDs, times, sizes), Noto Naskh Arabic (RTL). IDs/phone stay Latin in both languages; times use Arabic-Indic numerals in AR.

6 · Audit findings this resolves

  • One canonical offline / divider treatment — single hairline token, replacing the three offline-banner variants & the heavy #D9D9D9.
  • Nav active state — the missing active indicator is now a filled jade tab (and an inset pill in the grouped direction).
  • Consistent radii — student card no longer the off-grid 18 between tokens; circles use radius-full, not 216.
  • Dark mode is real per-screen — driven by tokens, not hardcoded dark-content status bars.
  • RTL chevrons + layout mirror — chevrons flip; logical inline spacing throughout.
  • Header consistency — every stack screen uses the same scaffold (no bespoke 22px / 56px Info Center header).
  • Open Dynamic text-size: the picker stores a preference; making it actually rescale type is a follow-up (centralize the type scale, then multiply).
