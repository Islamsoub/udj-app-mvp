UDJ — Info Center Spec

Implementation reference for the polished Centre d'information / مركز المعلومات screen, in the Soft Elevated language. Reached from Settings → Centre d'information. A help hub with contacts, an expandable FAQ accordion, and downloadable documents. The only screen in the set with an interactive accordion. Values are the source of truth; wire as tokens. Supports light, dark, RTL.

One vertical scroll, mixing two list styles: TileGroup (icon-led, for contacts & documents) and InsetGroup (text-led, for the FAQ accordion). This is intentional — the FAQ is text-dense and reads better without leading icons.

5 States

StateTreatment
LoadedAs specified — Contacts (2) + FAQ (3, first open) + Documents (2).
FAQ — collapsed / expandedEach row toggles independently (local state). Chevron rotates 0↔90° over .2s; answer mounts/unmounts below. Multiple can be open at once (not an exclusive accordion). Default: row 1 open.
Loading / skeletonTwo TileGroups → group skeletons (chip + label bars); FAQ → 3 collapsed question-bar skeletons. SkeletonBox shimmer.
Empty no FAQ/docsUnlikely (static content), but if a section is empty, hide that group entirely rather than render an empty card. If the whole screen has no content, centered empty block: 64 jadeFaint circle + info icon + "Aucune information disponible."
ErrorShared error block (72 circle + icon, title/body, retry 168×48) if remote help content fails to load.
Offline cachedShared OfflineBanner at top; FAQ + contacts render from cache. Document rows show a subtle "indisponible hors-ligne" state (value→text3, chevron dimmed) if the file isn't cached.

8 Dark mode & RTL

Dark mode

  • Surfaces/text/hair swap via tokens; chips lift accents.
  • FAQ answer text uses text2 (#9DB0A8) — verify it clears AA on surface #17211D.
  • Chevron stroke is token-driven (text3); rotates the same in both themes.
  • Status bar glyphs token-driven — never hardcode dark-content (current build does).

RTL (Arabic)

  • Root direction: rtl; back button + all chevrons flip.
  • FAQ chevron: base flips for RTL, then rotates 90° on open — verify it points sensibly (down) when expanded.
  • Contact values ("Bât. A · 8h–16h" → "مبنى أ · ٨–١٦") use Arabic-Indic numerals.
  • Copy from t('info.*'); font Noto Naskh Arabic. Verify dark+AR together.
