UDJ — Storage Detail Spec

Implementation reference for the polished Stockage hors-ligne / التخزين دون اتصال screen, in the Soft Elevated language. Reached from Settings → Stockage hors-ligne (and the Profile Documents quick-action). A usage-breakdown screen with a total ring, per-category rows, and a destructive clear action. Values are the source of truth; wire as tokens. Supports light, dark, RTL.

1 Layout tree (render order)

StorageScreen // Scaffold: status bar + compact header, single vertical scroll ├─ StatusBar 44 tall ├─ Header BackButton + "Stockage hors-ligne" 20/800 └─ ScrollBody (top:96 → bottom, paddingBottom 92) ├─ TotalCard surface card · ring + total + note │ ├─ Ring 132 jade fill at 62%, hair2 track │ │ └─ Center "12.4" mono 22 + "MB" 12 │ └─ Column storageTotal 15/700 + storageNote 13 ├─ TileGroup "Gérer le cache" │ ├─ TileRow Cours cal · blue · 4.8 MB │ ├─ TileRow Présence sync · amber · 1.7 MB │ ├─ TileRow Actualités news · danger · 2.4 MB │ ├─ TileRow Notes doc · violet · 3.1 MB │ └─ TileRow Profil&QR user · jade · 0.4 MB └─ ClearButton full-width tonal-danger "Vider le cache"

One vertical scroll. Total card on top, category breakdown in a single tile group, destructive clear action at the bottom (outside the group). Category values are mono and sum to the ring total.

5 States

StateTreatment
LoadedAs specified — total card + 5 category rows + clear button.
Loading / skeletonTotal card → 132 round skeleton + two bars; 5 row skeletons (chip + label + value bar). Clear button hidden until loaded. SkeletonBox shimmer.
Empty nothing cachedRing shows 0 MB (track-only). Category group replaced by a centered empty block: 64 round jadeFaint circle + storage icon, title 16/700, body 14/text2 ("Aucune donnée hors-ligne. Le contenu se mettra en cache à l'usage."). Clear button hidden.
Clearing in progressAfter confirm: clear button → disabled with inline spinner + "Suppression…"; on done, screen transitions to Empty.
ErrorShared error block (72 circle + icon, title/body, retry 168×48) if usage fetch fails.
Offline expectedThis screen is inherently about offline data, so it works offline by design. If currently offline, optionally show the shared OfflineBanner; the "Dernière synchro." value (from Settings) contextualizes freshness. Cached sizes render normally.

7 Differences vs current build

  • add Visual usage ring (62% of allotment) — the current build shows only a number; the ring makes proportion legible.
  • chg Category icon circle fixed: current build uses radius 9 (off-grid, between rSm/rMd) → standard 34×34 chip at radius 11.
  • chg Total value uses DM Mono (was sans); aligns numeric display with the rest of the app.
  • chg Clear action is tonal-danger and routed through the confirm sheet (was a bare destructive button).
  • chg Grouped elevated card replaces full-bleed rows; header uses shared Scaffold; status bar token-driven.
  • keep Reuses TileGroup, TileRow, ClearCacheConfirm, Scaffold.

8 Dark mode & RTL

Dark mode

  • Total card → surface #17211D; ring track hair2 (#fff@13%) keeps the unfilled arc visible.
  • Ring fill jade→#2BB989; mono total uses text1 #ECF1EE.
  • Clear button: danger→#FF6B6B on dangerBg@15%.
  • Category accents lift per the dark chip palette.

RTL (Arabic)

  • Root direction: rtl; back button mirrors; chips trailing, sizes leading.
  • Ring numerals stay LTR ("12.4 MB"); category sizes stay Latin DM Mono.
  • Copy from t('storage.*'); category labels translated (المقررات، الحضور…).
  • Clear button full-width — mirrors cleanly. Verify dark+AR together.
