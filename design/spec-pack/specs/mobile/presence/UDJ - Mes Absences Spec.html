UDJ — Mes Absences Spec

Drop-in spec for the new Mes absences / غيابي section on the existing Présence screen. Everything else on that screen — the Scaffold header (status bar + back button + “Présence” title), hero ring and Par matière subject cards — stays exactly as built and is out of scope. This is a body-only change: it replaces the single blind “Justificatifs” upload row with a list of individual absence records the student can see, filter, and justify one-by-one, plus a redesigned per-record justification sheet with a note field. Same Soft Elevated language (cardShadow, no borders), same tokens, same shared Sheet / SheetBtn / CatIcon / Scaffold. Light, dark & RTL. Values are the source of truth — wire as tokens, don't hardcode.

Still one vertical scroll — the absence list is a plain stacked list inside the page scroll (no nested scroll, no carousel). The section sits exactly where the old Justificatifs label/row was (same 22/20/10/20 label margin), so nothing above it shifts.

Header is untouched. The shared Scaffold renders as today — status bar on T.bg (no green), back circle 38×38 surface + cardShadow, compact title big=false → 20 / 800 / -0.6, scroll body top 96. The green only ever appears inside the hero card. Do not add a coloured status-bar fill, a right-side action, or a large title — none of that is part of this change.

Rejected is deliberately muted (text3), not red. Red stays reserved for “needs action / unjustified”; rejected reads as a calm “try again” and stays re-actionable. The danger count badge on the filter still counts rejected rows (they're actionable) even though their row tint is neutral.

Submit: POST /student/attendance/:id/justification — multipart { file, note }. The existing endpoint already takes the file; add the optional note part → persists to justificationNote. On 200: set that record's justificationStatus = PENDING, stash the note, close sheet, show success toast/snackbar; the row re-renders to the pending badge with its note line. The list is always scoped to the current semester — no semester switcher here.

11 Dark mode & RTL

Dark

  • List card, rows, hairlines, textarea, chips all swap via tokens (surface #17211D, surface2 #1E2A25, hair2 #fff@13%).
  • Status tints lift: jade→#2BB989, amber→#F0A84B, danger→#FF6B6B; date-tile + badge bg use the lifted token at the same faint alpha.
  • Rejected stays neutral (surface2 + text2) so it doesn't read as an alert in the dark list.
  • Sheet, picker tiles, preview and toast inherit the shared dark Sheet — no bespoke dark values.

RTL (Arabic)

  • Row mirrors: date tile → trailing edge, badge + chevron → leading; chevron flips (scaleX -1).
  • Filter segments, chips, picker tiles and footer buttons all mirror via direction:rtl.
  • Date day number stays Latin DM Mono; month abbrev localizes (mars → مارس). Time keeps Latin mono digits, matching the screen's other numerals.
  • Subject, notes, labels, badges from t('presence.*') in Noto Naskh Arabic.
  • Counter “0/80” mirrors position but digits stay Latin (mono).
  • Verify dark + AR together — especially the reject banner and preview chip.

12 Differences vs current build

  • remove The single blind “Justificatifs” UploadRow (auto-grabbed the first absent record). Justification is now per-record and contextual.
  • replace UploadSheet → JustifySheet: adds a context header for the chosen record, an optional note field + quick chips above the picker, and read-only / resubmit modes.
  • add Mes absences list of individual records with four visible statuses + a “À justifier / Tout” filter (default À justifier).
  • add Backend column justificationNote, sent with the file to the existing upload endpoint.
  • keep Scaffold header untouched — status bar, back button, “Présence” title and the hero ring + Par matière subject cards stay exactly as built. Sheet, SheetBtn, CatIcon base, OfflineBanner and toast are reused, not forked.
