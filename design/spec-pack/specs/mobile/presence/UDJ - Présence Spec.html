UDJ — Présence Spec

Implementation reference for the polished Présence / الحضور screen and its justification-upload flow, in the Soft Elevated language (matches Profile). Reached from the Profile Présence quick-action. Values are the source of truth; wire them as tokens — don't hardcode. Supports light, dark, and RTL.

1 Layout tree (render order)

PresenceScreen // Scaffold: fixed status bar + compact header, single vertical scroll ├─ StatusBar 44 tall · time + signal/wifi/battery ├─ Header (non-scrolling) │ ├─ BackButton 38×38 circle · surface · cardShadow · RTL-flips │ └─ Title "Présence" 20 / 800 └─ ScrollBody (top:96 → bottom, paddingBottom 92 to clear floating nav) ├─ HeroSummaryCard jade gradient · ring + rate + badge + summary │ ├─ DepthCircle decorative, absolute, clipped │ ├─ RingStat 96 ring, white track, "87%" mono center │ └─ Column rateLabel · StatusPill · summary ├─ SectionLabel "Par matière" ├─ SubjectList column, gap 10 │ └─ SubjectCard ×4 dot + name + sessions + pct + bar + projection ├─ SectionLabel "Justificatifs" └─ UploadRow icon chip + label + hint → opens UploadSheet UploadSheet // overlay above everything, over scrim ├─ Scrim rgba(16,22,20,.45) · tap to close └─ Sheet bottom, top radius 24, slide-up ├─ GrabHandle 38×5 ├─ Title + Subtitle ├─ DropZone dashed border · upload icon · hint ├─ PrimaryBtn "Choisir un fichier" └─ OutlineBtn "Annuler"

The whole body is one vertical scroll (no nested scroll regions, no horizontal carousels). Header and status bar are pinned. There are no filter tabs — see §5.

7 Differences vs current build

  • add Screen didn't exist as a polished surface — this introduces the Soft Elevated treatment (matches Profile).
  • add Single canonical 87% overall figure in the hero ring. The current app shows Présence stats in two places with conflicting numbers/colors — consolidate to this one source.
  • add Level-driven color system (ok/warn/danger) unifying dot + percent + bar + projection. Replaces ad-hoc per-row coloring.
  • add Projection line per subject ("2 absences restantes" / "Limite atteinte") — actionable, not just a number.
  • chg Justification entry promoted to a first-class card + bottom-sheet flow (drop zone + picker), instead of a buried button.
  • chg Header uses the shared compact Scaffold (no bespoke 22/56 header) and the floating nav is cleared by paddingBottom 92.
  • keep Reuses Scaffold, Sheet, SheetBtn, SkeletonBox, OfflineBanner, error block — no new chrome.

8 Dark mode & RTL

Dark mode

  • Surfaces, text, hair, skeleton all swap via tokens (surface #17211D, text1 #ECF1EE, hair2 #fff@13%).
  • Hero gradient is unchanged — jade is the brand anchor; the card stays bright in dark mode.
  • Level colors lift for contrast: jade→#2BB989, amber→#F0A84B, danger→#FF6B6B. Percent + bar fill follow.
  • Bar track uses hair2 (lighter in dark) so low percentages stay visible.
  • Status bar glyphs + back chevron are token-driven — never hardcode dark-content.

RTL (Arabic)

  • Root direction: rtl — back button + chevron flip to the right edge.
  • Depth circle uses insetInlineEnd so it stays in the trailing corner.
  • Status dot, ring, and percent mirror with the row; ring numerals stay LTR ("87%").
  • All copy from t('presence.*'); subjects use Arabic-Indic numerals in sessions ("١٩/٢٠ حصة").
  • Font switches to Noto Naskh Arabic; mono percent/ID stays Latin DM Mono.
  • Drop-zone, buttons and section labels all mirror; verify in dark+AR together.
