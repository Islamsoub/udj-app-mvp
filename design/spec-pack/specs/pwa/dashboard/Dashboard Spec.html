Tableau de bord — Build Spec

Pixel-exact spec of the student dashboard, with the sidebar open and closed, at every screen width. The reference build (dashboard.html in this package) uses the original stylesheet copied byte-for-byte, so it matches the app pixel for pixel. Open it, resize the window and compare. The previews below are that same file rendered live.

Reading your screenshots: they were taken on a ~1.35× display (Windows scaling), so 1912 screen px ≈ 1416 CSS px. Every value in this document is in CSS px. Divide screenshot measurements by 1.35 before comparing. Example: sidebar 323 px on screen = 240 CSS px.

Topbar

Flex, space-between, gap 16. Bell: 38×38 circle, bg surface2, icon 18, hover jade-faint/jade-text. Badge dot: 8×8 danger at top 6 / inline-end 6, ring 1.5px surface2. Avatar: 36×36 circle, jade-faint, gap 8 to a 13 px chevron in ink3. Bell opens .notif-panel (320 w, r16). Avatar opens .dropdown (min 220, r16, items 40 h). Both sit 8 px below their button, aligned to the inline-end.

Card base

.card: bg surface, 1px hair, radius 16, padding 20, shadow-card. .card-head is a flex row, space-between, mb 14.

① Aujourd'hui

Countdown pill: inline-flex, gap 6, bg jade-faint, padding 5 11, pill radius, mb 14. Each .mini-class row: flex, gap 12, padding 12 0, border-top hair. The first row has no border and no top padding. Its 4×38 rail (r4) is colored per course. The time column is pushed to the end with margin-inline-start:auto.

② GPA hero + Assiduité (stacked, gap 16)

Hero: radius 22, padding 18 (overrides 22), white text, gradient and glow from §4. Order: label → value (mt 6) → mention badge (mt 10, padding 5 12, gap 7, bg 18% white). Clicking the badge goes to Notes. Assiduité: card with padding 16 and flex:1, so its bottom lines up with card ①. The .gauge-wrap row has gap 16. The whole card is clickable and goes to Présence.

③ Notifications

Rows: flex, gap 10, padding 10 0, border-top hair on every row (the first one too, which draws the line under the header). Chip: 32×32, r8, icon 15. Grades chip is jade-faint/jade-text, attendance is warning-bg/warning, exams is exam-bg/exam. Clicking "Tout voir" opens the bell panel.

④ Accès rapide

h3 mb 12. Tile .qlink: flex, gap 11, padding 13 14, r16, 1px hair, bg surface. Hover: border jade, bg jade-faint, text jade-text. Icon tile: 36×36, r10, svg 18 (stroke 1.8).

⑤ Actualités récentes

The list has gap 10. .article-card2: flex, gap 12, padding 14, r16, shadow-card, no border. Thumb: 56×56, r12. Top row: category pill (11/700, padding 4 10) and date with a 7 px unread dot in jade. The title sits below it.

Bottom tab bar (mobile)

Fixed to the bottom, 64 tall, surface, border-top hair. 5 equal tabs: Accueil · Agenda · Notes · Actualités · Profil. Each has a 21 px icon, gap 3 and a 10.5 px label. Default ink3, active jade. Présence is not in the tab bar; it is reached from the Assiduité card.

9 · Hardening for in-between widths

css/hardening.css adds no visual change at the reference sizes. It only stops wrapping and overflow at awkward widths and on narrow phones:

minmax(0,1fr)card grid and quick-access tracks, so long words can never widen a column past the screen
No-wrappage title, Voir tout / Tout voir, mention badge, countdown pill, nav labels, news date
Ellipsispage title and course titles truncate instead of pushing the time column out
min-width:0on flex text columns (course body, notif text, quick tile and its text) so they can shrink; quick-tile titles wrap normally
Tablet railApplied by a pure CSS media query @media (min-width:640px) and (max-width:1023px) (72 px width, brand/labels/collapse hidden), so it never depends on JS timing. The body.tablet JS toggle is kept only as a fallback.
<380 pxquick-access tiles go to 1 column; gauge gap 12

Rule of thumb: no fixed heights on text boxes, every grid track is 1fr inside min-width:0 parents, and sizes switch only at 640 and 1024.
