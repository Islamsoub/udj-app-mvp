1 · Layer stack (what sits on what)

  1. Page — #screen-login, full viewport, bg --bg. Flex, centered both axes, padding 24px.
  2. Card — .login-card, width 100%, max-width 420px, bg --surface, radius 24px, shadow 0 12px 32px rgba(30,35,31,.12), overflow:hidden (clips hero to the card's top corners).
  3. Hero (top of card) — gradient bg, position:relative; overflow:hidden, text-align center, color #FFF.
  4. 3a · Blob 1 — circle 180×180, top −70px, inline-start −40px, rgba(255,255,255,.07). Absolute, behind content.
  5. 3b · Blob 2 — circle 160×160, top −50px, inline-end −50px, rgba(255,255,255,.07).
  6. 3c · Language chip — absolute, top 14px, inline-start 14px, z-index 2 (above blobs).
  7. 3d · Logo → Title → Tagline — relative-positioned so they paint above the blobs.
  8. Body — .login-body, padding 28px 28px 30px. Vertical order: [error card] → ID field → password field → offline row → forgot link → primary button → demo hint.
  9. Overlays — toast stack (bottom 24px, centered, z 900). Demo control rail (bottom-right, z 500) is prototype-only, do not ship.
