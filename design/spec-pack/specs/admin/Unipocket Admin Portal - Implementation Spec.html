Admin Portal — Implementation Spec

Complete, build-ready specification for the Unipocket Admin Portal — the web dashboard that university staff use to manage students, grades, attendance, news, schedule and system settings for the UDJ mobile app. This document captures every design token, component, screen, interaction, animation, validation rule and sample dataset in the reference prototype so it can be rebuilt faithfully in Next.js (or any framework). All copy is French; the interface is single-language (FR) by design.

How to read this spec Sizes, colors, radii and spacing are taken verbatim from the reference build — do not round to an 8px grid. Off-values (13.5px, 9px radius, #EEF2F0) are intentional. Every measurement below is a real value from the prototype, not an approximation. The reference is a React + inline-style SPA; production should re-implement it as a token-driven component library.

1 Architecture & stack

The reference is a single-page React application. State is entirely in-memory (no backend) with a seeded dataset. Production should map this to a Next.js app with a real API; the structure below is the intended target.

Reference build (as-is)

  • React 18 + inline styles, no CSS framework
  • Hand-rolled client router: single route = {page, params} state object, go(page, params) to navigate
  • One design-token object C, one Icon component (inline SVG), shared primitives on window
  • Global modal store (AdminUI.open / close) + global toast (notify)
  • Deterministic seeded sample data (mulberry32 RNG, seed 20260609)

Recommended production target

  • Next.js App Router; one route segment per page in the routing map (§8)
  • Design tokens as CSS custom properties / Tailwind theme; primitives as a component library
  • Server data via API; the entities in §9 are the schema
  • Toaster + modal provider at layout root
  • RBAC: 4 roles (§24) gate pages & actions; every mutation writes an audit entry (§25)
Locale Interface language is French only. Week runs Dimanche → Jeudi (Djibouti working week). Timezone Africa/Djibouti (GMT+3). Numbers format with toLocaleString('fr') (space thousands separator, e.g. 2 480). Grades on a /20 scale.

6 UI infrastructure

Global modal store + ModalRoot

A tiny pub-sub store holds one modal node. AdminUI.open(node) / AdminUI.close(). ModalRoot renders a fixed full-screen scrim (rgba(16,22,20,.45) + blur(2px), z 60, padding 24, animation fadeIn .16s), centers the modal, closes on scrim mousedown and on Esc.

Modal shell

Props: title, sub, icon, iconTone, width=480, children, footer. Card radius 18, maxWidth 94vw, maxHeight 90vh, shadow 0 24px 60px rgba(10,30,22,.30), animation popIn .18s cubic-bezier(.2,.9,.3,1). Header: optional 38×38 tinted icon tile (tone jade/danger/amber/blue) + title (17/700) + sub (12.5 text2) + close X. Body padding 22, scrolls. Footer (optional): right-aligned actions, surface2 bg, top hairline.

Form helpers

  • FRow — grid, cols columns (default 2), gap 14, margin-bottom 14.
  • FField — label (12.5/600 text2) with red * when required; shows error (11.5 danger) or hint (11.5 text3) below.
  • TextInput — same visual as Input; mono switches font; readOnly → surface2 bg, text2, not-allowed cursor; error → danger border; focus ring matches error/normal state.

Dropdown (custom select)

Closed control looks like an Input with a chevron-d that rotates 180° when open. Options accept [value,label] tuples, plain strings, or objects (supporting badge). Popover: absolute, +6px below, radius 11, shadowLg, maxHeight 260 scroll. Selected option → jadeFaint bg + jadeText 700 + trailing check (or badge). Closes on outside mousedown. disabled → 0.55 opacity, not-allowed.

Menu (context "…")

Quiet icon button (default more) opens an absolute popover (min-width 190, radius 11, shadowLg, +4px below, aligned right by default). Items: {icon, label, onClick, tone} or {divider:true}. tone:'danger' → danger text + dangerBg hover. Stops click propagation (so row clicks don't fire). Closes on outside mousedown.

ConfirmModal

Built on Modal, width 440. Danger by default. Optional requireText gates the confirm button until the user types the exact string (used by Close-semester which requires typing the semester label). confirmKind defaults dangerSolid. onConfirm may return {keep:true} to keep the modal open (e.g. show a generated value).

DatePicker

Trigger chip (cal icon + "20 juin 2026" + chevron). Popover 260px calendar: month nav, Mon-first weekday header L M M J V S D, French month names, selected day filled jade. allowed prop restricts clickable days (used by session marking → only session dates 3/10/17/24). Optional presets row (7 jours / 30 jours / Ce semestre) as jade pills.

RichText editor

contentEditable with a toolbar: B / I / U (execCommand), divider, H2 (formatBlock), unordered + ordered list, divider, link (prompt for URL → createLink). Placeholder via [data-ph]:empty:before. min-height configurable (default 200), optional rtl. The News editor uses a trimmed variant with H3 instead of H2.

Computed logic

  • NF per subject = 0.4·CC + 0.6·CF (null if CF missing).
  • GPA = coefficient-weighted mean of non-null NFs: Σ(NF·coef) / Σcoef.
  • Credits = round((gpa≥10 ? 1 : gpa/10) · 32), out of 32.
  • Status: idx 0 forced active; else 5% suspended; else gpa<10 || presence<75 → risk; else active.
  • SUBJECT_PROGRESS: entered = count of non-null CF; published = id !== 'INF304' (so INF304 is the one "Brouillon").
  • Dashboard aggregates: totalStudents 42, avgPresence (rounded mean), avgGpa, pendingJust 9, atRisk (status=risk count), gpaDist buckets (<10, 10–12, 12–14, 14–16, 16+), presenceTrend 8 weeks [82,85,84,88,86,89,87,87].
