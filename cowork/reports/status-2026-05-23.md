# Unipocket — Daily Status 2026-05-23

## Where we are

Unipocket is in the MVP build-out and polish phase — all 13 in-scope screens are implemented, and the Android-first, offline-first architecture is in place and working: SQLite stale-while-revalidate through the `useOfflineQuery` hook, a clean axios service layer with automatic 401 refresh and a queued-retry mechanism, and JWT/refresh tokens held in expo-secure-store. The most recent milestone, completed in the early hours of 23 May, was the full dark-mode rollout (Phases 1–3) across all 63 files, including theming the splash screen and the jade-on-jade borders. The single next priority is closing the Login screen's biometric authentication gap — the biometric button currently navigates straight to Home with no identity check — after which the four remaining features can be finished and the build taken to beta.

## Open issues

No nightly scan report (`cowork/reports/scan-*.md`) exists yet — the `cowork/reports/` folder did not exist before today, and `cowork/` contained only `dashboard.html`. The items below were identified during today's direct review of the source files, not from a triaged scan, and should be confirmed by the first nightly scan.

**Critical**

- **Login biometric bypass** — `app/(auth)/login.tsx`: `biometricHandler` calls `router.replace('/(tabs)/home')` with no `expo-local-authentication` check. Anyone holding an already-provisioned device can tap the biometric button and enter the account without any identity verification. Project security rules are all P0.

**Important**

- **Clear-cache action does nothing** — `app/settings.tsx`: the `ClearCacheConfirm` modal's `onConfirm` is an empty function, so the destructive "Vider le cache" action silently no-ops.
- **API base URL is hardcoded** — `constants/api.ts` sets `API_BASE_URL = 'https://udj-api.onrender.com'` directly (with a `// TODO` acknowledging it), instead of reading `EXPO_PUBLIC_API_URL`. This violates the project rule and blocks dev/staging/prod switching.

Cleanup-tier observations, not counted toward the score: the Settings language picker doesn't call `i18n.changeLanguage`; the Grades "Contact" and Schedule iCal-export handlers are `console.log` stubs; InfoCenter PDF download and search are non-functional; the backend declares both `bcrypt` and `bcryptjs`.
